## WEB APP MIGRATION PLAN

将 React Native 应用转为 Web App 的完整改动清单。

### 框架 & 路由

| 现在 | Web 替换 |
|------|---------|
| React Native | React + Vite 或 Next.js 14（App Router） |
| React Navigation（Stack + Tab） | Next.js 路由 或 React Router v6 |
| `useNavigation().navigate('Screen')` | `router.push('/screen')` 或 `<Link>` |
| `useRoute().params` | `useParams()` 或 searchParams |

**推荐：Next.js 14 App Router**，原因：SSR 对 SEO 友好，file-based routing 直接对应现有页面结构，API routes 可用于敏感操作。

### 样式系统

| 现在 | Web 替换 |
|------|---------|
| `StyleSheet.create({})` | Tailwind CSS（推荐）或 CSS Modules |
| `colors/spacing/fontSize` tokens | 保留 tokens，转为 CSS variables 或 Tailwind config |
| `View` / `Text` / `ScrollView` | `div` / `p,span` / `div overflow-y-auto` |
| `Pressable` | `button` 或 `div onClick` |
| `Animated` / `Reanimated` | Framer Motion 或 CSS transitions |
| `SafeAreaView` | `padding-top: env(safe-area-inset-top)` |
| `KeyboardAvoidingView` | 不需要（浏览器原生处理） |

### 手势 & 交互

| 现在 | Web 替换 |
|------|---------|
| `react-native-gesture-handler` Swipe | Framer Motion `drag` 或 自定义 mouse/touch handlers |
| CheckIn 卡片滑动（核心功能） | Framer Motion `useMotionValue` + `drag="x"` — 这是最复杂的改动 |
| `GestureDetector` / `PanGesture` | `onMouseDown/onTouchStart` + position tracking |

### 通知

| 现在 | Web 替换 |
|------|---------|
| `expo-notifications` | Web Push API（需要 Service Worker） |
| `notificationScheduler.ts` | 重写为 Web Push + 后端 cron（Supabase Edge Functions） |
| 本地 schedule | 移到服务端调度（用户不在时也能收到） |

> ⚠️ Web Push 需要 VAPID keys，比移动端 push 复杂，MVP 可以先用邮件提醒代替

### 存储

| 现在 | Web 替换 |
|------|---------|
| `AsyncStorage` | `localStorage` 或 `sessionStorage` |
| Supabase（已是 REST/JS SDK） | **无需改动** |

### 截图分享

| 现在 | Web 替换 |
|------|---------|
| `react-native-view-shot` + `expo-sharing` | `html2canvas` + `navigator.share()` 或直接下载 |

### 不需要改动的部分
- ✅ **Supabase** — JS SDK 浏览器端直接用
- ✅ **Claude API 调用** — HTTP 请求，浏览器完全支持
- ✅ **所有业务逻辑**（contexts、utils、types）— 纯 TypeScript，平台无关
- ✅ **checkinLLM.ts / checkinSummary.ts / auditScorer.ts** — 无 RN 依赖
- ✅ **Supabase schema** — 不动

### 建议迁移顺序

```
1. 搭脚手架
   Next.js 14 + TypeScript + Tailwind + Supabase JS SDK

2. 迁移 Auth（最简单）
   - AuthContext 逻辑几乎不变，Supabase Auth 在 web 完全支持
   - 替换 AuthScreen 为 /login 页面

3. 迁移 Manager（纯展示，无手势）
   - 直接翻译 View/Text/StyleSheet → div/Tailwind
   - 日历部分可用 react-calendar 替代

4. 迁移 Settings、ReportScreen、AuditScreen
   - 无手势，主要是样式转换
   - AuditScreen 的 chat UI 在 web 更简单（原生 input/button）

5. 迁移 CheckInScreen（最复杂）
   - Swipe 卡片是核心交互，用 Framer Motion 重建
   - 建议先做 web 版"点击选择"降级方案

6. 通知系统
   - 移动端先保留，web 版用 email 提醒（Supabase SMTP）
```
